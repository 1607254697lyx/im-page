# I'm 个人主页编辑器

一个可以在浏览器中编辑、预览并导出个人主页的网页工具。支持头像和图片上传、模块调整、拍立得经历、摄影相册、Markdown 笔记中心、草稿与历史版本。

## 在线使用

打开 [I'm 个人主页编辑器](https://1607254697lyx.github.io/im-page/) 即可开始编辑。

编辑内容保存在当前浏览器中，不会自动上传到服务器。建议重要版本同时使用“导出配置”备份。

## 下载使用

1. 点击 GitHub 仓库右上角的 **Code**。
2. 选择 **Download ZIP**。
3. 解压下载的文件。
4. 双击根目录中的 `index.html` 打开编辑器。

请保留文件夹内部结构，不要单独移动 `index.html`，否则图片和编辑器资源可能无法加载。

## 制作与发布主页

1. 在右侧编辑区修改内容，左侧实时预览。
2. 点击“下载网页”可获得独立的个人主页 HTML。
3. 点击“发布”会生成名为 `index.html` 的网页文件。
4. 将生成的 `index.html` 上传到自己的 GitHub Pages 仓库即可发布个人主页。

## 安装为应用

通过 GitHub Pages 在线打开后，可以使用浏览器菜单中的“安装应用”或“添加到主屏幕”。

## 数据说明

- 自动草稿与历史记录保存在当前浏览器中。
- 清除浏览器数据可能同时清除草稿。
- 更换设备或浏览器时，请先导出配置文件，再在新设备中导入。
